## 🚀 About Me

<img align="right" alt="Coding" width="320" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif">

I'm a **Software Engineer** and final-year Software Engineering student at **PTIT**, passionate about designing, building, and deploying production-grade, reliable software systems.

My work bridges **scalable backend architecture**, **modern frontend engineering**, and **cutting-edge agentic AI workflows**.

- 🔭 Currently an **AI-Native Software Engineer Intern at Got It**, orchestrating LLM agent workflows (Claude Code) and developing backend services for complex voucher systems and enterprise portals.
- ⚡ **Core Tech:** Proficient in **Golang**, **Spring Boot**, **Python (FastAPI)**, **TypeScript**, **Next.js**, and distributed systems (**gRPC, Apache Kafka, PostgreSQL, Redis**).
- 🤖 **Agentic & AI Engineering:** Experienced in integrating LLMs via **Google ADK (Agent Development Kit)**, **Gemini API**, **LangChain**, **MCP (Model Context Protocol)**, and **CopilotKit** into production workflows with edge-case validation.
- 🛡️ **Software Quality:** Dedicated to high test coverage and reliability using **Playwright (E2E)** and **Vitest**, packaged with **Docker**.
- 🎯 Constantly exploring distributed systems, clean architecture (BFF, Server Modules), and shipping impactful software to production.
